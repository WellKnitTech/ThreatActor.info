## Description

Adversaries may utilize Direct Prompt Injection, Indirect Prompt Injection or other methods to instruct enterprise AI agents to exfiltrate data. [Prompt-Injection Exfil](https://arxiv.org/html/2608.27092) [Anthropic Report Sep 2026](https://www.anthropic.com/threat-intelligence-report-september-2026) When enterprise systems incorporate the use of AI assistants or other AI agents, adversaries may abuse these systems to weaponize sanctioned tools available to the agent. [Google Security State of Prompt Injections](https://blog.google/security/prompt-injections-web/) 

As an AI agent processes queries or ingests data, an injected prompt can cause the agent to use its tool connections in unauthorized or unintended ways. When AI agents are induced to exfiltrate data, other exfiltration techniques likely apply as well to transfer the information out of the network, such as Exfiltration to Code Repository or Exfiltration Over Web Service. [Google Cloud AI Risk Sep 2026](https://cloud.google.com/security/resources/ai-risk-and-resilience-2026) [Barracuda Prompt Injection Phishing Emails](https://blog.barracuda.com/2026/10/07/email-attacks-target-both-humans-ai-assistants)
