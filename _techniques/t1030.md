## Description

An adversary may exfiltrate data in fixed size chunks instead of whole files or limit packet sizes below certain thresholds. This approach may be used to avoid triggering network data transfer threshold alerts. [Chunked Encoding](https://requestly.com/blog/chunked-encoding/)
