## Introduction
StingyBasilisk is an unattributed espionage actor with active infrastructure since at least April 2022; its initial access vector is unknown. In February 2026, it expanded laterally using SMB and a modified Impacket atexec tool to execute commands through scheduled tasks. It maintains persistence through COM hijacking and abuse of the Windows Time service. Its custom agents relay C2 traffic through named pipes over SMB, while the Go-based HenMapCaCon.dll backdoor supports file access and exfiltration.
