## Introduction
Storm-3358 is a Cambodia-based, financially motivated intrusion cluster that primarily targets financial organizations in Southeast Asia. In October 2026, it began using the ARTEX framework alongside conventional tools to scan internet-facing systems and exploit flaws including anonymous file upload and SSRF. It has deployed the WISP, VShell, and AdaptixC2 RATs for persistence and lateral movement, using utilities such as netcat and curl to download them.
