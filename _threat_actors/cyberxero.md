## Introduction
CyberXero is a Russian-speaking, financially motivated IAB that conducts a global campaign against WordPress and e-commerce platforms alongside targeted reconnaissance of Ukrainian energy and utilities organizations. Its TTPs include exploiting disclosed vulnerabilities, using shared or default credentials, extracting victim databases and deploying Cobalt Strike. The actor’s infrastructure includes up to 51 specialized Claude Code agents and a PentAGI deployment connected to its Cobalt Strike Team Server. An exposed directory revealed session logs, exploitation tools and victim data, including confirmed data on more than 628,000 Ukrainian individuals.
